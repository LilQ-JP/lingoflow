# ADR-001 外部AIプロバイダー評価の入口

Status: blocked pending rights-cleared media and test credentials

## 確定した境界

- ASR、翻訳、LLM、TTSは `PipelineAdapters` の外部実装として差し替える。
- 外部AIへ送るのは必要な字幕範囲、言語、個人を直接示さない処理IDに限定する。
- 氏名、メール、検索履歴全体、不要なプロフィールは送らない。
- 生成物にはプロバイダー、モデル、プロンプト版、入力版、生成時刻を記録する。

## 実測前に必要なもの

1. 音声処理を許可された30分素材
2. 候補事業者の保存期間・再学習利用・データ地域の確認
3. テスト資格情報
4. 正解字幕と、人が確認した表現・問題の評価セット

## 比較指標

- 30分素材の総処理時間とp95
- 字幕誤り、重大な意味反転、問題の誤正解
- 動画1本当たりの費用
- 障害時の再試行と利用枠返還
- データ保持、学習利用、地域、削除方法

候補名だけで採用を決定せず、同じ評価セットの実測後に別ADRで確定する。
