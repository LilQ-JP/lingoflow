# Lingoflow Web vertical slice

日本語UI・英語学習に限定した最初の縦断実装です。Pingo AIの静かで余白のある体験を参考にしつつ、Lingoflowの Indigo / Coral とオリジナルの学習キャラクターで構成しています。

```bash
npm install
npm run dev
```

`http://127.0.0.1:3000/` で、次の流れを確認できます。

- ローカル検証ログイン、18問のレベルテスト、目標ヒアリング、編集可能なロードマップ
- ホーム、動画検索導線、学習、マイの4タブ
- YouTube公式IFrame再生、字幕同期、700msプリロール、フレーズ移動、1文リピート、速度変更
- 単語解説と保存、ブラウザ音声APIによる発話練習
- 4択、並べ替え、文字・音声入力へ進む段階式クイズ、同日再出題、対象外と復元
- 午前4時基準の進級・降格・習得判定と、サーバー側の学習記録・設定保存

記録は `.data/learning-records.json` に0600権限で保存され、Git管理対象外です。同じローカル検証ユーザーで別ブラウザからログインすると記録を復元できます。

Google・Apple OIDC、PostgreSQL、AI動画解析、YouTube検索API、ジョブキュー、通知配信、教材のオフライン保存は未接続です。ローカル検証ログインは開発時だけの代替経路です。発話練習の実機マイク・権限拒否動作は端末確認が必要です。サンプル字幕は内部技術検証用で、公開配信権利を確認済みという意味ではありません。

キャラクター画像はOpenAI内蔵の画像生成ツールで作成しました。生成指示は「既存作品に依存しない、水滴のような流体キャラクター。Cyan / Indigo / Lavender / Soft Pinkの発光グラデーション、ヘッドホン、透明背景、文字やロゴなし」です。
