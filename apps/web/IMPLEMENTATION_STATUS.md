# 実装状況

更新日: 2026-09-07

## このブランチで動作する範囲

`feat/integrated-learning-app` は、既存スパイクをPingo AIのような静かで親しみやすいWebアプリ画面へ統合した縦断実装です。

ログイン代替 → ホーム → YouTube動画 → 字幕同期・700ms巻き戻し → 単語解説 → 発話練習 → 段階式穴埋め → 学習記録保存、という一連の操作がつながっています。設定、保存動画、学習中・対象外の表現、午前4時基準の継続記録も同じサーバーストアから復元します。

## 現在の境界

- 英語学習・日本語表示だけを実データ対応とし、他言語は将来追加できる選択UIまでです。
- 動画と字幕は権利確認済みデータを想定した固定サンプルです。動的AI解析と字幕供給判定は未接続です。
- 動画検索はYouTube検索ページへの安全な導線です。YouTube Data API検索・チャンネル新着取得は未接続です。
- 認証はローカル検証ユーザーです。Google / Apple認証と本番DBは未接続です。
- 発話評価はブラウザが認識した文字列との一致率です。発音の音響評価ではありません。
- オフライン教材、プッシュ通知、課金、管理・通報は未実装です。

## 次の段階

次は設計索引に従い、字幕の出所・利用可否・再生可否を返す `ContentAccessDecision` を実サービス側へ接続します。その後に30分解析ジョブ、共通キャッシュ、利用枠の予約・消費・返還を実装します。外部資格情報を使う段階までは、本ブランチを画面と学習ロジックの比較基準として保持します。
