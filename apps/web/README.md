# Lingoflow Web vertical slice

日本語UI・英語学習に限定した最初の縦断実装です。

```bash
npm install
npm run dev
```

`http://127.0.0.1:3000/` で、ローカル検証ログイン、英語選択、YouTube再生、字幕同期、700msプリロール、4択クイズ、サーバー側学習記録まで確認できます。記録は `.data/learning-records.json` に0600権限で保存され、Git管理対象外です。同じローカル検証ユーザーで別ブラウザからログインすると完了数を復元できます。

Google・Apple OIDC、PostgreSQL、ジョブキューは外部設定の決定と資格情報が必要なため未接続です。ローカル検証ログインは開発時だけの代替経路です。サンプル字幕は内部技術検証用で、公開配信権利を確認済みという意味ではありません。
